# 翻译说明

## 独立来源

译文直接从官方英文源逐项编写，依据英文内置帮助、Unraid 英文文档及原生解析器确定上下文。未打开、克隆、下载或复用任何中文翻译仓库。网页搜索曾返回中文仓库的搜索摘要，但未将其作为译文或术语来源。

保留原有英文键、大小写、重复记录和多行区块标签。仅对译文应用中文引号、中英对照和西文括注规则；代码和技术语法保持原样。

## 源格式修复

`Cleanup Appdata/cleanupappdata.txt` 中，以 `Note that this module reviews all of your previously installed Docker Containers` 开头的一整段英文缺少等号，不是有效的翻译记录。

构建时按官方查词规则生成去除格式标点的键，并补上独立中文译文。其余原有键不变。这使单行记录由 5,182 条变为 5,183 条。

上游含 12 次文件内重复键记录，保留原顺序，并统一同键译文，避免加载时产生不同语义。去重后连同多行帮助，官方 PHP 解析器实际加载 5,804 个键。

## 上下文处理

- Array 译为「阵列 (Array)」，不译为程序语言中的「数组」。
- Parity 译为「奇偶校验 (Parity)」，区分检查、同步、修正和重建。
- Emulated 解释为「内容由阵列模拟提供」，避免误解为另有一份完整实体副本。
- Mirror 指镜像冗余，Image 指磁盘或容器镜像文件。
- Public / Secure / Private 分别为「公开 / 受限 / 私有」，帮助中说明访客与写入权限。
- Preclear 使用「预清零 (Preclear)」，与格式化、擦除和普通清零分开。
- 「Command times」按对应帮助译为「命令耗时」，而非命令超时。
- 英文帮助对 IPvlan 的表述容易使人误以为它不能接入物理网络；依据 Docker 官方文档澄清为共享父接口 MAC、容器仍可接入物理网络，同时保留原有链接。
- Windows 文件名大小写说明按 Samba 的默认客户端语义表述，避免将「Windows 从不支持大小写敏感」写成绝对事实。
- BLAKE2 帮助中的 proprietary solution 按插件实现语境处理，未将 BLAKE2 算法本身描述为闭源算法。
- 旧许可证、旧缓存设置、旧版文件系统及 My Servers 名称随源仓库保留，不把历史文案改写成新的产品政策。

## 上游运行时限制

原生 JavaScript 生成器存在 `Yes` / `No` 的保留键归一化问题，详见 README 及校验后生成的 `build/javascript-result.json`。此问题不能仅靠常规语言条目完全修复，因此本包保留正确译文，不注入脚本、不改写 WebGUI 程序。

翻译包不会改变任何存储、权限或网络功能。对按钮和帮助的译文校验，不能替代实际操作前对当前系统状态的确认。
