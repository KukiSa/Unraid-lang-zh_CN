:ud_settings_smb_security_plug:
> 设置 SMB 共享的访问级别：
>
> + **已禁用**：禁用 SMB 共享。
> + **公开**：公开共享设备、远程 SMB / NFS 共享和 ISO 挂载，允许读写。
> + **私有**：启用 SMB 安全控制，按用户设置是否允许访问及是否允许写入。
> + **私有且隐藏**：启用 SMB 安全控制并隐藏共享，同样按用户设置访问和写入权限。
>
> Windows 服务器签名：
>
> 如果 Windows 11 24H2 或更新版本无法浏览 SMB 共享，可能需要适配服务器签名 (Server Signing) 要求。Unraid 已启用服务器签名，访问公开共享时可能需要额外步骤。
> 可以<a href='https://techcommunity.microsoft.com/t5/storage-at-microsoft/accessing-a-third-party-nas-with-smb-in-windows-11-24h2-may-fail/ba-p/4154300' target='_blank' rel='noopener noreferrer'>在 Windows 中禁用该功能</a>；若要保持签名启用，最简单的办法是在 Unraid 中创建与 Windows 账户同名的用户并设置密码，Windows 随后应会要求输入凭据。
> 使用 Microsoft 账户时，更适合在 Unraid 中创建名称简单的用户并设置密码，再在 Windows 的「控制面板 → 凭据管理器 → Windows 凭据 → 添加 Windows 凭据」中，填写正确的 Unraid 服务器名称及凭据。
:end

:ud_settings_case_sensitive_plug:
> 控制文件名是否区分大小写。
>
> 默认值**自动**允许支持大小写敏感文件名的客户端（Linux CIFS 和 NFS）逐个数据包告知 Samba，应按 UNIX 的大小写敏感语义访问文件系统。
> Windows 客户端通常不使用这种语义，因此「自动」对其相当于「否」，但仍会保留 Windows 传入的文件名大小写。目录很大时，Samba 需要搜索并匹配名称，可能降低性能。
>
> 设为**是**，文件按客户端传入的大小写创建，访问时也必须完全匹配。这可加快大目录访问，但某些 Windows 应用可能无法正常工作。例如，创建的是 MyFile，而应用尝试打开 MYFILE，便会找不到文件。
>
> **强制小写**是特殊模式：所有客户端传入的文件名（不只是新文件名）均转为小写。无论 Windows 端使用何种大小写，存储和访问时都使用小写。这可确保 Windows 应用不受大小写影响而找到文件，但目录列表不再保留原大小写。
:end

:ud_settings_nfs_security_plug:
> 设为**是**，通过 NFS 导出 Unassigned Devices。公开共享允许读写，私有共享使用你设置的规则。实际访问还受文件和文件夹权限控制。

:ud_settings_nfs_rules_plug:
> 每个 IP 地址的规则独占一行，最后一条规则后也必须换行。
> 不能使用 IP1,IP2(...) 格式，Unraid 不会以此格式生成 exports 文件。

> 每条 NFS 规则默认包含 async 和 no_subtree_check。

> **注意：**
>
> 公开共享的默认规则为 '*(rw,sec=sys,insecure,anongid=100,anonuid=99,all_squash)'。
>
> 私有共享的默认规则为 '*(rw,sec=sys,insecure,anongid=100,anonuid=99,no_root_squash)'。
:end

:end

:ud_remote_server_test_plug:
> 远程服务器必须启用 SMB 和 / 或 NFS。此测试检查相应端口是否开放。Unraid 上运行 'showmount -e <server>' 还必须能列出可用 NFS 共享。

> SMB 端口开放时，远程 SMB 才会被判定为在线。

> NFS 端口必须开放，且 'showmount -e' 必须列出 NFS 共享，远程 NFS 才会被判定为在线。即使端口开放，命令未列出共享时，NFS 仍无法使用。

> 如果可访问的远程服务器（例如群晖）未通过 showmount 返回任何 NFS 共享，通常有以下原因：

> 未导出 NFS 共享：

> 服务器可能未将任何目录配置为 NFS 导出。请检查群晖的 NFS 配置，确保目标文件夹已明确导出。

> 访问限制：

> NFS 共享可能按 IP 限制访问。群晖允许为每个共享指定可访问的 IP 地址或网络。如果本机 IP 不在允许列表中，showmount 不会显示该共享。

> NFS 服务未启用：

> 在群晖 DSM 的「控制面板 → 文件服务 → NFS」中检查并启用 NFS。

> 防火墙或网络配置：

> 群晖防火墙可能阻止 showmount 请求或所需 RPC 通信。请允许 NFS 相关端口流量，通常为 NFS 的 2049 和 RPC 的 111。

> 群晖导出选项：

> 某些配置需要在顶层启用 NFS；若客户端需要 NFSv3，还应允许 NFSv3。请在「控制面板 → 文件服务 → NFS」中确认。

> 确保 NFS 已启用、权限配置正确，且导出目录允许客户端 IP 访问后，showmount 应能列出可用导出。
:end
