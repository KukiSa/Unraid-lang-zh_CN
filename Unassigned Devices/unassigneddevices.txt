:unassigned_devices_general_help_plug:
> **Unassigned Devices 简称 UD。**
>
> 将鼠标悬停在 UD 页面的可操作区域上，会显示点击后的作用说明。
> UD 可以挂载 USB 设备、SATA 驱动器、远程 SMB / NFS 共享和 ISO 文件。开启「自动挂载」的设备会在阵列 (Array) 启动时挂载。阵列停止时，所有驱动器和 SMB / NFS 挂载均会在 stopping_svcs 事件中卸载。
> 要共享驱动器，可开启其共享开关。远程 SMB 共享默认允许公开读写，可在 Unassigned Devices 设置中按用户启用 SMB 安全控制。NFS 共享以读写方式导出，导出功能也在该设置中启用。
> 还可配置通用脚本，在每次挂载磁盘时执行。共享 UD 设备时，需要先在设置中启用共享，再打开该设备的共享开关。远程 SMB / NFS 共享和 ISO 挂载始终会共享。
> 输入挂载点后，按 &lt;Enter&gt; 保存更改。
>
> 点击设备标识旁的 <i style='color:black;font-weight:bold;' class="fa fa-plus-square"></i> 图标可查看更多选项。磁盘未挂载时，可更改挂载点，同时也会更改磁盘卷标。还可格式化磁盘或运行 fsck 检查。
>
> 必须在「设置 → Unassigned Devices」中正确配置 SMB 和 NFS 安全设置，共享才能正常工作。
>
> 如果远程 SMB / NFS 共享的挂载按钮不可用，表示远程服务器未响应 ping。远程服务器必须响应 ping，否则 UD 会认为它已离线。
>
> 「启用磁盘共享 (Disk Share)」开启时，「添加根共享 (Root Share)」按钮不可用，之前添加的根共享也无法挂载。
>
> UD 的破坏性操作模式 (Destructive Mode) 允许删除磁盘分区和格式化磁盘。未在 UD 设置中启用时，无法执行这些操作。可前往「设置 → Unassigned Devices」启用。
>
> **格式化磁盘：**
>
> + 必须启用破坏性操作模式。
> + 必须移除磁盘上的全部分区。先卸载磁盘，点击 <i style='color:black;font-weight:bold;' class='fa fa-plus-square'></i> 图标，再依次点击所有 <i style='color:red;font-weight:bold;' class='fa fa-remove hdd'></i> 图标删除分区。
> + 如果磁盘已预清零 (Preclear) 且「格式化」按钮不可用，点击 <i style='color:black;font-weight:bold;' class='fa fa-plus-square'></i> 图标，再点击 <i style='color:red;font-weight:bold;' class='fa fa-remove hdd'></i> 图标，删除预清零状态文件。
>
> **注意：通过 UD 分区的磁盘与阵列分区布局兼容，可加入阵列。支持 XFS、加密 XFS、BTRFS、加密 BTRFS、ZFS 和加密 ZFS。**
>
> **加密磁盘：**
>
> + 默认情况下，在 UD 中格式化的加密磁盘使用阵列密码 / 密码短语，可以加入阵列。也可在格式化时设置独立磁盘密码；挂载这类磁盘时，需在「Unassigned Devices → 设置」中输入该密码。
>
> **Unassigned Devices 脚本：**
>
> UD 提供用于挂载和卸载设备及 SMB / NFS 共享的脚本，可按需在命令行或自己的脚本中使用。
>
> + '/usr/local/sbin/rc.unassigned mount autodevices'：挂载所有设为自动挂载的设备。
> + '/usr/local/sbin/rc.unassigned mount autoshares'：挂载所有设为自动挂载的 SMB / NFS 共享。
> + '/usr/local/sbin/rc.unassigned umount auto'：卸载所有设为自动挂载的设备和 SMB / NFS 共享。
> + '/usr/local/sbin/rc.unassigned umount all'：卸载所有设备和 SMB / NFS 共享，为停止阵列做准备。
> + '/usr/local/sbin/rc.unassigned mount /dev/sdX or devX'：挂载磁盘设备。
> + '/usr/local/sbin/rc.unassigned mount name=diskname'：按磁盘名称挂载设备。
> + '/usr/local/sbin/rc.unassigned umount /dev/sdX or devX'：卸载磁盘设备，可在 UD 脚本完成时使用。
> + '/usr/local/sbin/rc.unassigned umount name=diskname'：按磁盘名称卸载设备。
> + '/usr/local/sbin/rc.unassigned spindown /dev/sdX or devX'：使磁盘停转。
> + '/usr/local/sbin/rc.unassigned spindown name=diskname'：按磁盘名称使其停转。
> + '/usr/local/sbin/rc.unassigned detach /dev/sdX or devX'：断开 USB 磁盘设备，可在 UD 脚本完成时使用。
> + '/usr/local/sbin/rc.unassigned detach name=diskname'：按名称断开 USB 磁盘，可在用户脚本完成时使用。
> + '/usr/local/sbin/rc.unassigned attach serial'：连接磁盘设备，可在脚本中使用。设备断开时，diskname 不可用。
> + '/usr/local/sbin/rc.unassigned mount source'：挂载共享，其中 source 为 SMB / NFS 源。
> + '/usr/local/sbin/rc.unassigned umount source'：卸载共享，其中 source 为 SMB / NFS 源。
>
> 注意：/dev/sdX 中的 X 是设备标识字母；devX 是 UD 页面中的设备名。如果显示为 Dev 1，则停转命令中使用 dev1。用户脚本需要对磁盘执行 UD 操作时，使用 name=diskname 较方便。
>
> 请谨慎使用 /dev/sdX 或 devX，因为它们可能在重启后改变。最好使用传入 UD 脚本的 sdX (DEVICE) 和 devX (UD_DEVICE) 值。
:end
