Hide Deprecated Applications=隐藏已弃用的应用
This setting hides deprecated applications from the list of available apps Deprecated apps will still however display within the installed and previous apps sections=从可用应用列表中隐藏已弃用的应用。这些应用仍会出现在「已安装应用」和「曾安装的应用」中
Hide Incompatible Applications=隐藏不兼容的应用
This setting will hide applications that are listed as being incompatible with your version of Unraid=隐藏已知与你的 Unraid 版本不兼容的应用
Allow install of second instance=允许安装第二个实例
This option enables another button on the cards and popups which will allow you to reinstall an installed application using its default template values This option can be confusing at times, and is only generally used if you wish to install and have an application running twice simultaneously=在应用卡片和弹出窗口中增加一个按钮，允许使用模板默认值再次安装已安装的应用。此选项可能造成混淆，通常仅在需要同时运行同一应用的两个实例时使用
Automatically open the sidebar=自动打开侧栏
Allows CA to automatically open the sidebar for more information when hovering over an application's icon=鼠标悬停在应用图标上时，允许 CA 自动打开侧栏显示更多信息
Allow CA to check for updates to applications=允许 CA 检查应用更新
This setting enables CA to check for updates to applications Note that Community Applications will always check for updates to itself=允许 CA 检查应用更新。无论此设置如何，Community Applications 始终会检查自身更新
Disable Mouse Wheel Page Changes=禁用鼠标滚轮翻页
This setting disables using left or right on a mouse wheel to change the page=禁止通过左右倾斜鼠标滚轮来翻页
Mouse wheel threshold=鼠标滚轮阈值
If you tilt the mouse wheel left or right, the browser returned value will change Set the threshold to the value returned Note that different browsers and operating systems may return different values=左右倾斜鼠标滚轮时，浏览器返回的值会发生变化。请将阈值设为返回的值。不同浏览器和操作系统可能返回不同的值
This is a global value for all devices If it causes issues, then disable Mouse Wheel Page Changes=此设置对所有设备生效。如果出现问题，请启用「禁用鼠标滚轮翻页」
Allow CA to send any emergency notifications=允许 CA 发送紧急通知
This setting allows CA to periodically scan your system and alert you to the presence of=允许 CA 定期扫描系统并就以下问题发出警报
1 Known malware and security vulnerabilities within applications=1 应用中已知的恶意软件和安全漏洞
2 Critical security vulnerabilities within Unraid OS=2 Unraid OS 中的严重安全漏洞
3 Any installed applications which may seriously hinder the operation of your server=3 可能严重影响服务器运行的已安装应用
Save CA debugging information=保存 CA 调试信息
Only enable this when advised to from the author of Community Applications=仅在 Community Applications 作者要求时启用
Enable developer mode=启用开发者模式
This unlocks some extra features within CA generally only used by developers Not recommended to enable=解锁 CA 中通常仅供开发者使用的额外功能，不建议启用
